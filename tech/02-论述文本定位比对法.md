# 02-论述文本定位比对法

> 适用：论述类 / 实用类文本阅读的客观选择题（论点、论据、推断题）。
> 核心：错项几乎都是「原文有句长得极像、但被改了一个词」的陷阱句——把选项拆开，回原文逐句对，不凭印象判。

## 验证

| 字段 | 值 |
|---|---|
| 验证状态 | 真题验证 |
| 验证场景 | 2026 新高考一卷 |

## 一句话概括

论述类选择题：圈选项关键词，回原文逐句比对找陷阱。

## 方法详解

论述类文本选择题的错误项，几乎不外四类：

1. **无中生有**：选项说的事，原文根本没提。
2. **偷换概念**：把 A 概念换成近义词，或扩大、缩小范围。
3. **以偏概全**：用局部当整体，常带「都 / 全 / 必然 / 所有」。
4. **因果倒置 / 强加因果**：把「因→果」反过来，或把并列说成因果。

**操作步骤：**
- 先读题干，圈出限定词（第几段、关于谁）。
- 逐项读选项，标出三类高危词：**绝对化词**（都 / 全 / 必然 / 只要…就 / 唯一）、**因果词**（因为 / 所以 / 导致 / 源于）、**比较级**（更 / 最 / 首要）。
- 带着这些词回原文找对应句，比对时只看「这个词在原文里到底是不是这个意思」，不做整体感觉判断。
- 拿不准时，错项往往藏在「原文有一句几乎一模一样、只改了一两个词」的句子里。

## 最小例题

选项：「人工智能将必然导致传统职业全面消失。」
回原文找对应句：「部分传统职业可能被重新定义，但总体就业结构会调整而非消失。」
比对：选项用「必然」「全面」偷换原文的「可能」「部分 / 调整」，属偷换概念 + 绝对化 → 判错。

## 备注

- 论述类文本最忌「读着像对的就选」——像，是因为错项本来就是照原文改词造的。
- 推断题的「推断」必须能在原文找到依据，纯逻辑推演不算对。
- 时间紧时优先用绝对化词排雷，效率最高。
