## 📟 一句话概括

收录高考各科选填题/大题的**通用方法**、**特殊技巧**、**二级结论**与**秒杀套路**，助你在选填题上抢时间、卡壳时蹭步骤分。每条技巧自带「验证状态」，**不分科全适用**，靠可信度筛选。

## 🛠️ 快速开始

> 本仓库结构极简：`tech/` 目录下每条 `.md` 文件即一条技巧，含标题 / 正文 / 验证状态 / 验证场景。

1. **浏览技巧索引** —— 见 [`tech/README.md`](./tech/README.md)，每条技巧一行，带验证状态标签
2. **复制模板** —— [`tech/_template.md`](./tech/_template.md)，填好标题、正文、验证状态、验证场景
3. **提交 PR** —— 云端 `gh pr create`，我负责建文件、补索引

## 📊 验证状态（三档筛选）

| 状态 | 含义 | 能不能用 |
|---|---|---|
| `⚪ 未验证` | 纸面推导，未实战 | 考前不用 |

| `🟢 真题验证` | 在历年真题中验证过 | **可用** |
