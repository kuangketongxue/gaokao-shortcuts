# gaokao-shortcuts

> 高考选填题抢分技巧速查 — 特殊技巧 / 二级结论 / 秒杀套路

## 简介

收录高考的"特殊技巧""二级结论""秒杀套路"，面向两类场景：

- ⏱️ **选填题抢时间** —— 用二级结论 / 特殊技巧跳过繁琐推导
- 🆘 **大题卡壳骗分** —— 卡住时用套路蹭步骤分

⚠️ 详见顶部免责声明：技巧仅作辅助，**不替代对底层核心概念的扎实理解**，务必先在模拟考验证适用性再用。

## 组织方式

**方法通用，全科全适，不分科、不分范围。** 每条技巧自带「验证状态」，按可信度筛选。
项目规则见 [`CLAUDE.md`](./CLAUDE.md)。

## 目录

- [`tech/`](./tech) —— 所有技巧文件（扁平列表，每条一个 `.md`）
- [`tech/_template.md`](./tech/_template.md) —— 技巧模板，复制即用
- [`tech/README.md`](./tech/README.md) —— 技巧索引 + 验证状态说明

每条技巧只含：标题 / 正文 / 验证状态 / 验证场景。
**验证状态**分三档：`未验证`（考前不用）/ `模拟考验证`（谨慎）/ `真题验证`（可用）。

## 图片与公式

- 数学公式优先用 LaTeX（`$...$` / `$$...$$`，GitHub 原生渲染），别用截图。
- 化学方程式 / 结构式 GitHub 不渲染，用纯文本或图。
- 配图放 `tech/assets/`，相对路径引用。

## 贡献

欢迎补充新技巧、修正错误、适配新高考方向。提 PR 时请：

- 复制 `tech/_template.md` 建文件，**填全所有字段**（尤其验证状态）。
- 附**验证场景**（某次模拟考 / 真题年份）；未验证技巧明确标 `未验证`。
- 在 `tech/README.md` 索引补一行。
- 发现错误或过时技巧：改其「验证状态」并注明原因，不直接删文件。
